# Tallybook week-2 churn

Tallybook is a bookkeeping app for freelancers. About 31% of new paying users cancel between day 8 and day 14.
This repository holds the analysis of why.

- `data/README.md`: the tables in the analytics snapshot (`data/snapshot.duckdb`, built with `make snapshot`, not committed).
- `docs/experiments.md`: every idea tested so far, with its result.
- `notes/anomalies.md`: things we saw and could not explain.
- `analysis/`: one notebook per tested idea.

Owner: Mara (product analytics).
